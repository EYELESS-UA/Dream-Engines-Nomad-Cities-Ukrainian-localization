## 📂 Структура проекту

* `src/source/` — оригінальні англійські файли локалізації (зазвичай CSV, JSON або XML). **Не редагувати!**
* `src/translation/` — робочі файли, де ведеться переклад інтерфейсу, інфраструктури та сюжетних квестів.
* `build/` — готова до гри збірка українізатора.

## 🤝 Як долучитися до розробки

Світ гри містить чимало специфічних механік (електричні мережі, вага міста, паливо для перельотів). Ми раді допомозі з перекладом великих масивів тексту та технічних описів будівель.

1. Зробіть **Fork** цього репозиторію.
2. Редагуйте файли виключно у папці `src/translation/`.
3. Створіть **Pull Request** (PR) із описом ваших змін.

> ⚠️ **Важливо:** Не ламайте керуючі теги, змінні (наприклад, `{0}`, `{Energy}`, `{Weight}`) та символи форматування рядків Unity.

Якщо ви помітили орфографічну помилку, неперекладений опис юніта або вихід тексту за межі інтерфейсу — створіть **[Issue](https://github.com/EYELESS-UA/Dream-Engines-Nomad-Cities-Ukrainian-Localization/issues)** та додайте скріншот.
